# 知识库使用与维护指南

运维平台的「知识检索」模块（`/knowledge`）提供两类内容：

1. **内置 FAQ**：随软件发布的高质量运维排查知识（磁盘满、CPU 高、OOM、网络不通、MySQL/PG/Redis、K8s、Docker、证书、SSH、监控告警治理等 30+ 条），开箱即用、不可删除。
2. **自维护知识**：团队在实践中沉淀的条目，持久化保存（随平台重启不丢失），可新增/编辑/删除。

## 一、如何检索

- 在「检索」标签页输入**现象或报错关键词**（中文/英文/报错片段均可），例如：`磁盘空间不足`、`采集不到数据`、`内存泄漏`、`OOM`、`CrashLoopBackOff`。
- 检索匹配维度：标题、关键词同义词、标签。多词以空格分隔，任一词命中即召回。
- 检索结果以卡片展示，点击任意卡片（或键盘 Enter/空格）打开**详情弹层**，查看完整可执行的排查步骤。

## 二、如何查看详情（点击查看）

- 检索结果卡片、知识库条目卡片均**可点击**：单击打开「知识详情」对话框，展示完整内容、标签与来源。
- 键盘可达：`Tab` 聚焦卡片 → `Enter` 或 `空格` 打开详情。
- 内置 FAQ 详情由 `/api/knowledge/:id` 实时拉取；自维护条目直接读取本地存储。

## 三、如何维护自维护知识

- 「知识库」标签页右上角「新增知识」：填写标题、内容（step-by-step 排查过程）、标签（逗号分隔）。
- 卡片右侧删除图标（内置条目无删除图标，仅自维护条目可删）。
- 后端接口：`GET /api/knowledge`、`POST /api/knowledge`、`PUT /api/knowledge/:id`、`DELETE /api/knowledge/:id`、`GET /api/knowledge/:id`、`GET /api/knowledge/search?q=`。

## 四、如何扩充内置 FAQ（开发者）

内置知识源位于 `src/diagnostics/knowledge.mjs` 的 `FAQ` 数组。新增条目：

```js
{
  id: 'kb-unique-id',                 // 稳定唯一 id，供详情接口命中
  title: '人类可读标题',
  keywords: ['中文同义词', 'english', '报错片段'], // 提升召回
  tags: ['分类', '标签'],
  a: '1) 步骤一；2) 步骤二；…',        // 可执行排查/解决步骤
}
```

- 修改后重新构建（`npm run build`）即可生效。
- 若需对接外部知识库（如运维 FAQ 系统、向量检索），替换 `searchKnowledge` / `listBuiltin` / `getBuiltinById` 的实现即可，接口签名保持不变。
