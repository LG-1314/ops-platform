## 一、最终决策（相对 PRD 的一处关键变更）

| 决策点 | 结论 |
|---|---|
| 图表库 | **改用 `@mui/x-charts` 的 `LineChart`**（而非 recharts）。原因：`@mui/x-charts@^7.29.1` 已在 `dependencies` 且 `Dashboard.tsx` 已使用，是活跃依赖；引入 recharts 会造第二个图表库 + ~110KB gz，违背单一依赖/主题一致。 |
| SMTP | 引入 `nodemailer@^6.10.1`（dependencies）+ `@types/nodemailer`（devDependencies，nodemailer 无内置类型）。 |
| 采集/留存 | 60s 周期、24h 留存（环形缓冲 1440 点），本期不可调。 |
| 端点 | `GET /api/metrics/history?assetId&from&to`（已同步修订 `Spec.md`）。 |
| 敏感字段加密 | 邮件 `smtpPassword` + webhook/飞书/钉钉 `secret` 一并 AES-256-GCM 加密落盘（`*Enc`），列表 `mask()` 脱敏。 |
