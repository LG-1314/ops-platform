## 3. 设计缺陷与缺失模块（现状）

1. **持久化层**：JSON 原子写 + 独立时序文件（metrics.json/health.json）已覆盖重启不丢；>24h 归档未做（设计取舍，非缺陷）。
2. **RBAC 粒度**：`admin`/`personal` 两角色，无资源级权限与前端操作审计页（后端审计已具备，前端查看页可后续加）。
3. **告警闭环**：去重已修；收敛/抑制/值班（on-call）未做，大规模下仍可能告警疲劳（业界 Prometheus+Alertmanager 对标项）。
4. **CMDB/配置中心对接**：资产手动录入 + discover，无服务树/CMDB 对接。
5. **APM/分布式追踪**：应用自身监控依赖 process 指标，无采集链路耗时观测。
