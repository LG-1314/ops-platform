# PRD - 企业级运维监控管理平台 v2.0

> 生成日期：2026-08-17
> 作者：许清楚（产品经理）｜ 团队：MVP 开发专家团

## 1. 产品定义

**一句话**：开箱即用的一体化桌面运维工作台，SSH 免 Agent 深度采集 + 统一告警 + 多系统连接，卡在「监控强但难用」（Zabbix/Prometheus）与「易用但监控浅」（1Panel/Uptime Kuma）之间的市场空白。

**部署形态**：Electron 桌面应用（Windows exe，双击即用）。

## 2. 目标用户

- **主要**：中小企业 IT 运维 / SRE（1-5 人），管几十台服务器，要深度监控但不想学 PromQL、不养 Prometheus 堆栈、用不起 Datadog。
- **次要**：IT 服务商 / MSP、DevOps 工程师、个人站长。

## 3. 核心问题

当前运维工具割裂：监控（Zabbix/Prometheus）、面板（1Panel/宝塔）、数据库、K8s、云 API 分散在 4-5 个工具里，学习成本高、部署维护重。需要一个开箱即用、SSH 直连、统一收口的一体化工作台。

## 4. 差异化定位

1. **SSH 免 Agent 深度采集**：竞品都要装 Agent/Exporter，我们 SSH 直连，接入门槛趋零。
2. **统一告警引擎**：阈值告警 + 飞书/钉钉/企微/邮件 + 收敛降噪/静默/排班（开源市场空白，夜莺靠付费 FlashDuty 才补）。
3. **一体化收口**：监控、面板、数据库、K8s、云 API 统一在一个桌面工作台。

## 6. 给架构师 / 设计师的关键输入

- UI 对标 Grafana（暗色数据风 + 精美图表），配色企业深蓝 + 语义色（禁紫粉渐变），图标用统一 SVG 图标库。
- 告警是最该建的护城河，优先做降噪/静默/排班。
- 接入层优先 SSH 免 Agent，Agent 留作 P2 可选（内网/无 SSH 场景）。
